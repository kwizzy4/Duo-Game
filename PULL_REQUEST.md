# Quiz Duo — интерактивный квиз-сайт (JS + HTML + CSS)

## Описание

Полностью автономный сайт-квиз без внешних зависимостей и без бэкенда:
вся логика, база вопросов и хранение рекордов работают в браузере
(`localStorage` + WebAudio). Ветка `qwen-code-2e2ee784-2c89-49c0-98a0-c4786cfe2818` → `main`.

**Изменения:** 4 файла, +2030 строк
| Файл | Строк | Назначение |
|---|---|---|
| `index.html` | 265 | SPA-структура из 6 экранов: Главная · Темы · Подкатегории · Настройки · Игра · Результаты |
| `css/style.css` | 468 | Две темы оформления на CSS-переменных, glassmorphism, анимированный фон, адаптивные сетки, прогресс-бар, кольцо таймера |
| `js/data.js` | 444 | База вопросов: Спорт, Автомобили, Видеоигры, Кино, Наука, IT, География, Музыка, Еда, История — с подкатегориями |
| `js/app.js` | 853 | Игровая механика, настройки, звуки, подсказки, статистика, горячие клавиши |

## Что реализовано

### Темы и подкатегории
- **Спорт** → Футбол, Хоккей, Баскетбол, Теннис, Олимпиада, Киберспорт
- **Автомобили** → Марки авто, Модели авто, Технологии, История автопрома
- **Видеоигры**, **Кино и сериалы**, **Наука**, **IT и технологии**, **География**, **Музыка**, **Еда и кулинария**, **История**
- Отдельный выбор подкатегорий внутри темы + мультивыбор тем
- Режим **«Случайный микс»** — вопросы из всех тем сразу

### Уровни по количеству вопросов
Выбор до старта квиза: **10 · 15 · 25 · 50 вопросов**.
Доступные подуровни зависят от объёма выбранного пула (если вопросов мало — крупные уровни блокируются с подсказкой).

### Подсчёт очков
- Базовые очки за правильный ответ
- **Бонус за скорость** — чем быстрее ответ, тем больше очков
- **Комбо-серия**: множитель растёт за каждую верную ответ-серию, сбрасывается при ошибке
- Штраф/бонус в зависимости от режима (лёгкий → хардкор)
- Медали по итоговой точности: 🥇 / 🥈 / 🥉
- Таблица рекордов по каждой комбинации «тема + уровень» в `localStorage`

### Фишки для удобства
- ⏱ **Кольцевой таймер** на каждый вопрос с цветовой индикацией остатка времени
- ❤️ **Система жизней** (отключаемая в настройках)
- 💡 **Подсказки**: «50/50», «+10 секунд», «Голосование зала»
- 🔥 **Хардкор-режим**: один неверный ответ = конец игры, без подсказок
- ⌨️ **Горячие клавиши**: `1–4` ответ, `H` подсказка, `P` пауза, `Esc` выход, `Enter` старт
- 🌗 Тёмная / светлая тема + сохранение всех настроек между сессиями
- 🔊 Звуковые эффекты через **WebAudio** (без аудиофайлов), кнопка «без звука»
- ⏸ Пауза игры, подтверждение выхода, прогресс-бар по вопросам
- 🧠 **Интересные факты** после каждого ответа
- 📊 **Разбор ответов** на экране результатов: свой вариант vs правильный + факт
- 🔎 Поиск по темам на экране выбора
- 📱 Полностью адаптивная вёрстка (desktop / tablet / mobile)
- Повтор того же сетапа одним кликом или новый случайный микс

## Как запустить

Просто открыть файл в браузере:

```bash
open index.html            # macOS
xdg-open index.html        # Linux
```

или поднять локальный сервер (рекомендуется):

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

Внешние зависимости: **отсутствуют**. Требуется только современный браузер
(Chrome / Firefox / Safari / Edge).

## Как проверить вручную

1. Открыть сайт → выбрать тему (например «Автомобили») → отметить подкатегории.
2. Выбрать уровень **15 вопросов**, включить подсказки и жизни → «Старт».
3. Ответить правильно несколько раз подряд — проверить рост комбо и очков.
4. Нажать `H` → убедиться, что «50/50» скрывает два неверных варианта.
5. Пропустить вопрос таймером → жизнь должна уменьшиться.
6. Доиграть до конца → проверить медаль, разбор ответов и попадание рекорда в таблицу.
7. Переключить тему оформления и перезагрузить страницу → настройки должны сохраниться.

## Известные ограничения / следующий шаг

- Объём базы вопросов ограничен (~2000 строк данных) — для уровня 50 по одной узкой
  подкатегории пул может быть меньше запрошенного, тогда игра берёт столько вопросов,
  сколько доступно.
- Нет серверной части: рекорды хранятся локально в браузере, мультиплеер и
  глобальный лидерборд не реализованы.
- Планируется: экспорт/импорт своей базы вопросов в JSON, режим дуэли на одном устройстве,
  категории «Литература» и «Арт», PWA-манифест для офлайн-установки.
